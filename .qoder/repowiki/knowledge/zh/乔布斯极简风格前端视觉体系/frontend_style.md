## 1. 设计系统与美学理念
该系统采用**“乔布斯极简风格”**（Apple官网同款）作为核心设计语言，强调大留白、毛玻璃效果、圆角卡片及SF字体族。整体视觉追求高清晰度与工业级精致感，旨在为质检人员提供无干扰的数据监控环境。

### 核心视觉特征
- **毛玻璃拟态 (Glassmorphism)**：顶部导航栏使用 `backdrop-filter: saturate(180%) blur(20px)` 实现iOS风格的半透明模糊背景。
- **微交互与阴影**：卡片悬停时通过 `box-shadow` 和 `transform` 产生轻微上浮感，增强操作反馈。
- **语义化色彩体系**：严格遵循Apple Human Interface Guidelines的色彩规范，用于缺陷等级标识。

## 2. 技术栈与依赖
- **基础框架**：原生 HTML5 + CSS3。
- **样式方案**：纯 CSS，采用 CSS Variables (Custom Properties) 管理设计令牌。
- **交互逻辑**：jQuery 3.7.1 (CDN)。
- **数据可视化**：Plotly.js 2.27.0 (CDN)，用于渲染SPC控制图、缺陷分布饼图及AI预测折线图。

## 3. 设计令牌 (Design Tokens)
在 `src/main/resources/static/css/style.css` 的 `:root` 中定义全局变量：

| 令牌名称 | 值 | 用途 |
| :--- | :--- | :--- |
| `--bg` | `#f5f5f7` | 全局背景色 (Apple灰) |
| `--card-bg` | `#ffffff` | 卡片背景 |
| `--accent` | `#0071e3` | 品牌主色/按钮色 (Apple蓝) |
| `--radius` | `16px` | 统一圆角半径 |
| `--font` | `-apple-system, ...` | 系统字体栈，优先SF Pro |
| `--color-A` | `#FF3B30` | A类缺陷/高风险 (红) |
| `--color-safe` | `#34C759` | 安全状态 (绿) |

## 4. 布局架构
采用**左右二分栏**响应式布局（最小宽度1200px）：
- **左侧面板 (35%)**：数据录入区。包含基础信息、物测指标及四层外观缺陷（烟支/小盒/条盒/箱装）的分组表单。
- **右侧面板 (65%)**：可视化看板。包含历史数据表格、SPC监控图、缺陷综合分析图及AI预测大图。
- **置顶横幅**：风险状态横幅位于Header下方，根据后端返回的风险等级动态改变颜色（红/橙/黄/绿）。

## 5. 开发规范与约定
1. **字体渲染**：必须启用 `-webkit-font-smoothing: antialiased` 以确保在Mac/iOS设备上的字体清晰度。
2. **表单控件**：所有输入框聚焦时需显示 `--accent` 色的光晕 (`box-shadow: 0 0 0 3px ...`)。
3. **图表配置**：Plotly图表需统一使用 `LAYOUT_FONT` 配置，保持字体与页面一致；背景色设为 `#fafafa` 以融入卡片。
4. **缺陷着色**：A/B/C/D四类缺陷在输入框、表格单元格及图表中必须保持颜色一致性（红/橙/黄/灰）。
5. **滚动条美化**：自定义WebKit滚动条样式，宽度6px，颜色 `#c7c7cc`，避免默认粗大滚动条破坏极简感。
